# FIELDNOTES · 七宗罪 × 七美德

**这是 GitHub Pages 公开访问版**，作为本仓库 AI Interview Lab 之外的独立子站存在；现有面试网站的文件未作修改。

- 公开网页入口：`/ai-interview-lab/seven-vices-virtues/`
- `index.html` 和 `assets/`：已经构建的浏览器网页，可直接通过 GitHub Pages 访问。
- `source/`：React / Vite 源码；运行 `npm install && npm run build` 生成 `source/docs`，将里面的文件同步到本子目录根部。
- `source/public/assets/sins/`：经 WebP 优化的七幅原创卡牌，与线上资产为同一套文件。

体验包含 42 题 / 70 题、14 项独立计分、七张插画、雷达图、PNG 分享卡、进度续答、本地档案和含匿名结果的分享链接。

## 数据与测量边界

GitHub Pages 为纯静态服务，不运行 Cloudflare D1 后端。原 `chatgpt.site` 报告不能自动搬到这里；新版只把个人进度和报告储存在浏览器本地。复制分享链接时，匿名分数被序列化到 URL 片段中；有链接的人可读取、改写它，不是可验证的心理评估凭证。

这套问卷由本项目独立编制，未做信效度验证；仅供趣味自我觉察，不用于心理诊断或道德评价。

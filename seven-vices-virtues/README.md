# FIELDNOTES · 七宗罪 × 七美德

独立、开源、纯静态的原创趣味自我探索项目，延续 FIELDNOTES 的纯白、钴蓝与古典雕塑视觉语言。

## 功能

- 探索版 42 题 / 深入版 70 题，五级频率作答；14 个方向分别计分。
- 十四幅雕塑卡牌（七宗罪 + 七美德），双雷达、七组 3D 翻面卡、十四维分层解读与 PNG 报告下载。
- 答题自动进入下一题，维度打乱交错呈现；答题期间只显示总进度，不泄露特质分数。
- 分享长图包含十四轴双侧雷达、十四项独立分数与邀请好友独立测试的入口二维码。
- 未完成进度和历史报告留在当前设备的浏览器中。
- 将匿名汇总报告序列化进 URL 的 `#report` 片段，可跨设备分享，无后端、账号或密钥。

## 部署到 GitHub Pages

1. 新建一个 **Public** 仓库，不需要添加 README 或模板。
2. 将本目录的所有文件（包括 `docs/`）放在仓库根目录并提交到 `main`。
3. 到仓库 **Settings → Pages → Build and deployment**，选择 `Deploy from a branch`，`main` 分支，`/docs` 目录，保存。
4. 等待 GitHub Pages 部署。网址形式通常是 `https://<用户名>.github.io/<仓库名>/`。

本版本使用相对路径，仓库名无需写死。如需修改网站，安装 Node.js 22+ 后执行 `npm install` 和 `npm run build`；重新提交生成的 `docs/` 文件夹。

## 分数与边界

本问卷是未经心理测量学验证的原创自我觉察工具，不是心理诊断或道德评判。每个特质分别由 3 或 5 题观察，5 级选项映射到 0–4，反向题使用 `4 − 原值`，取平均再映射到 0–100。这里的分数**不是人口百分位**。

GitHub Pages 不提供服务器运行时；此公开静态版不含云数据库，也不会与原 `chatgpt.site` 的历史报告同步。共享链接中嵌入的只是匿名汇总报告，不包含单题答案，但知道链接的人都可查看或修改其内容。请不要将个人敏感信息写入报告标题或分享链接。

视觉卡牌由项目发起者提供。项目代码与问卷为独立实现；不包含第三方平台的专有后端或评分规则。

## 解读依据和局限

- 十四个维度按本次作答分为三个原创叙述区间（0–34、35–69、70–100），对应 42 段行为解读与小实验建议。区间不是社会常模，答案也不是对人品或心理健康的判定。
- 文案借鉴社会比较、情绪调节、拖延、自我控制、共情和人际边界等心理学研究方向；这些研究**不构成本问卷的信效度证据**。参见 NCME / APA / AERA 的测量规范、Gross 1998 情绪调节研究、Steel 2007 拖延元分析、Davis 1983 共情多维研究。
- 分享二维码固定指向测试首页 `https://hardzionl.github.io/ai-interview-lab/seven-vices-virtues/`，不含个人报告。分享图则包含本人匿名分数，请自行决定传播范围。

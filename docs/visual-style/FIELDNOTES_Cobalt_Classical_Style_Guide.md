## 1. 风格核心

**一句话定义：** 纯白留白底色上的古典大理石雕塑与宇宙图谱，以钴蓝作为唯一强强调色，融合铜版蚀刻、细线星图和现代编辑设计。

关键不是“黑底宇宙”或“普通蓝色科技插画”，而是三种视觉语言的平衡：

1. **古典艺术**：大理石雕像、古典柱式、拱门、神话式翅膀、手部、人物剪影。
2. **天体知识**：行星、月面、星云、轨道、星芒、天球网格、测绘刻度。
3. **编辑式印刷设计**：克制的留白、细边框、编号、短标题、精细排版与轻微版画颗粒。

最终观感应当明亮、精致、安静、神秘，有博物馆图录与艺术杂志的高级感。

## 2. 色彩规范

| 用途 | 建议色值 | 使用方式 |
|---|---|---|
| 主背景 | `#FFFFFF` | 必须是纯白，不使用米黄、灰黄或明显纸张底色 |
| 主钴蓝 | `#174BFF` | 视觉焦点：星体、翅膀局部、轨道块面、星芒 |
| 深钴蓝 | `#1036B8` | 蓝色阴影、深空局部、雕塑阴影中的冷色反射 |
| 深夜蓝 | `#10245E` | 只用于小面积宇宙暗部，不铺满整张背景 |
| 墨黑 | `#171717` | 蚀刻线、轮廓、文字、雕塑暗部 |
| 中性灰 | `#777777` | 次级刻线与细节 |
| 边框灰 | `#D4D4D4` | 卡片细边框、分隔线 |

**面积建议：** 白色与留白占主要面积；黑白雕刻负责形体；钴蓝用于建立视觉重心。蓝色可以鲜明，但不要把整张图涂成纯蓝。背景必须保持干净明亮。

## 3. 明暗与材质

- 雕塑使用高细节大理石质感：可见凿刻纹理、细微磨损、石材高光和自然阴影。
- 黑白区域采用铜版蚀刻、钢笔排线、点描、细颗粒网点；避免大块死黑。
- 宇宙元素使用高对比钴蓝星云、月面纹理、星点与细轨道线。
- 可叠加少量印刷错位、旧版画磨损和颗粒，但只作为局部材质，不要把白底弄脏。
- 线条要精细、可辨认；细节密集区旁必须留有安静区域，形成疏密对比。

## 4. 构图规则

### 独立竖版插画
- 推荐比例约 `1:1.9`，与八幅系列卡片的竖向版式相近。
- 主体应明确，通常占画面高度约 55%–75%；不要让多个主体争抢焦点。
- 四周留白充足，尤其标题区、主体边缘与底部标签区。
- 可用极细灰色边框或细线分隔，但边框应后期排版添加，不必烘焙进每一张原始插画。
- 轨道、星芒、网格等辅助元素用来引导视线，不可比主体更抢眼。

### 横版网站卡片
- 推荐比例约 `2.4:1`（例如 `1942×809` 或 `2400×1000`）。
- 不要简单把竖图强行拉宽；应重新安排主体位置，并为裁切和网页标题预留空间。
- 主体可偏左或偏右，另一侧保留呼吸感；缩小到卡片尺寸时，主体轮廓仍须清楚。
- 若从竖图制作横图，必须重新构图或智能裁切，禁止拉伸变形。

### 八幅系列拼版
- 采用 4 列 × 2 行的整齐网格，卡片宽高一致、间距均匀。
- 每张图可以有编号 `01–08`、简短英文标题和一行短主题词。
- 标题采用高对比衬线字体、小型大写字母、宽字距；编号与标题沿同一基线。
- 文字建议在网页或排版阶段叠加，避免让图像生成模型直接生成大量文字造成拼写错误。

## 5. 八个主题母题

后续扩展时可延续以下主题语言，但每张图都应有独立构图：

1. **ORBITAL MIND**：古典雕像侧脸、行星、轨道和知识的引力。
2. **MESSENGER**：单只大型精细羽翼、天球测绘线、运动与连接。
3. **THRESHOLD**：古典石拱门、银河旋涡、台阶与微小探索者。
4. **ASCENT**：飞升姿态的古典有翼雕像、星芒、云层与上升动势。
5. **RECOLLECTION**：古典人物侧脸、钴蓝几何碎片、记忆与自我。
6. **FARTHER STUDIES**：巨大月球、山脉、披风旅人、尺度与探索。
7. **THE OPEN HAND**：装饰性拱框、蛇形纹样、托举天体的手、分享与创造。
8. **CONTINUUM**：仰望的古典胸像、环绕轨道、行星与时间连续性。

可以替换具体对象，但必须保留“古典形体 + 宇宙图谱 + 钴蓝焦点 + 纯白留白”的组合逻辑。

## 6. 纹理与装饰的使用边界

**推荐：**
- 细十字星芒、少量圆点、轨道椭圆、天球网格、微小坐标标记。
- 轻微纸版印刷颗粒、点描、铜版排线、几何蓝色块。
- 不对称但平衡的构图，明确的视觉焦点和安静留白。

**避免：**
- 全黑或大面积纯黑背景。
- 米黄复古纸色、脏灰底色、过度做旧。
- 过量蓝色渐变、霓虹发光、廉价科幻 UI、随机 HUD。
- 装饰符号塞满每一个角落、主体互相重叠、细节没有主次。
- 人脸塑料感、翅膀像橡胶、错误的解剖结构、低分辨率模糊纹理。
- 随机生成的长段文字、错误字母、伪品牌标识、水印。
- 耳机女孩或与 Hermes 标识相关的角色形象；不直接复刻其他品牌官网的具体作品或版式细节。

## 7. 生成与后期工作流

1. **先定构图**：一次只生成一张独立插画；先确定主体、视线方向、留白位置和蓝色焦点。
2. **先生成无文字母版**：优先保证雕塑、羽翼、拱门、天体等主体细节；编号、标题、细边框之后用排版工具添加。
3. **检查白底**：背景应接近纯白 `#FFFFFF`；纹理只在局部出现，不可形成整体米黄滤镜。
4. **检查主体**：确认手指、翅膀、脸部、柱体和轨道结构合理，不能有明显粘连或变形。
5. **高清输出**：保存高分辨率 PNG 母版；网站使用时另导出高质量 WebP。
6. **横图单独构图**：`card-*` 资源必须按横向比例重新安排画面，不把竖图直接拉伸。
7. **网页缩略图验收**：将图缩小到真实卡片大小，确认焦点仍清晰、蓝色不过曝、白底不发灰。
8. **先审核后替换**：所有新图先做联系表/预览图供用户确认；未获确认前不覆盖线上资源。
9. **版本管理**：原 PNG、WebP 成品、提示词和版本说明分别归档；替换线上图片前创建 Git 分支或备份。

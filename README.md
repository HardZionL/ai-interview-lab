# AI Interview Lab · Art Edition

> 自用 AI 工程面试学习手帖。围绕 Agent / RAG / LLM / LangChain / AI 编程，采用“深入理解 → 独立口述 → 要点核对 → 巩固 / 追问”的学习模式。

**在线体验（需 GitHub Pages 已成功发布）：** https://hardzionl.github.io/ai-interview-lab/  
**原题资料来源：** [小林面试笔记 · 大模型面试题](https://xiaolinnote.com/ai/)  
**性质：** 非官方、独立整理的个人学习项目；与小林面试笔记及其作者没有合作或授权关系。

## 项目简介

AI Interview Lab 是一个可直接由浏览器运行的静态学习网页，以高频 AI 工程面试知识为主线组织 21 天学习路径。它不只是刷选择题：先提供原理、工程场景和误区，再让学习者尝试独立口述，最后核对答题要点，决定补基础、巩固或继续深入。

> **题目状态说明**：当前预置 21 天 × 5 题 = 105 个学习条目。其中 Day 1–2 的 10 题已有专项详解与来源核对；后续条目含待持续完善的内容。题量代表学习路径容量，**不代表 105 题都经过同等深度的逐篇校验**。

## 功能概览

| 功能 | 当前实现 |
| --- | --- |
| 逐日学习 | 从 2026-10-17 起，按 Asia/Singapore 日期解锁，每日 5 题 |
| 知识精讲 | 关键概念、原理拆解、案例和易错点；详略随题目完善状态而不同 |
| 口述与自查 | 文本作答、关键要点核对与自我熟练度评估 |
| 自适应练习 | 基于本地评分规则和自评结果，推荐补基础 / 巩固 / 追问 |
| 原站溯源 | 单题提供原站原题链接或专题入口，并区分链接核实情况 |
| 学习进度 | 当日完成情况、历史记录、薄弱项和进度概览 |
| 数据备份 | JSON 导入 / 导出，手动迁移个人学习记录 |
| UI | Art Edition 艺术编辑风格，适配桌面与移动浏览器 |

**能力边界**：当前版本**没有联网大模型语义评分**、账户系统或跨设备实时同步；“自适应”指规则驱动的本地学习路径推荐，而非在线 AI 面试官。每日新题预置在静态 HTML 中，不会自动抓取原站更新。

## 快速开始

### 方式一：在线访问

- Source：**Deploy from a branch**
- Branch：**main**

此项目没有构建步骤，也不需要安装依赖或提供任何 API Key。

## 学习方式

1. **理解原理**：阅读机制拆解、工程场景与常见误区；需要更完整原文时跳转至原站。
2. **独立口述**：脱离资料描述核心原理、边界条件和实际取舍。
3. **要点核对**：检查关键词与关键论点，并如实评价熟练度。
4. **自适应下一步**：薄弱题先补基础；达到要求后进入进阶追问或新知识点。
5. **长期复习**：通过学习报告筛选薄弱项并手动复习。

题目涵盖 Agent、RAG、LLM 工具调用、大模型工程、LangChain 和 AI 编程。

## 隐私、安全与数据

- 学习记录、口述文本、自评和进度默认保存于当前浏览器 `localStorage`，**不随网页源码提交 GitHub**，但能接触此浏览器配置文件的人也可能读取它们。
- 同一站点与浏览器可保留进度；从本地 HTML 切换到 Pages 域名，或者换设备，需要先导出 JSON，再在目标站点导入。
- JSON 备份可能含有个人口述内容：请保存在私人设备，**不要上传至公开仓库或 Issue**。
- 不要提交 `.env`、Token、API Key、私钥、服务账号凭证、真实个人身份信息。日后若集成模型 API，应使用服务端密钥管理和访问控制，不能把密钥写入前端。
- 打开原站链接可能向第三方网站发起网络请求；浏览器语音识别可能由浏览器厂商处理。详细说明请见 [PRIVACY.md](./PRIVACY.md)。
